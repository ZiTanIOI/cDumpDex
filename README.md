# cDumpDex

cDumpDex 是一款面向 Android 应用分析与安全研究的脱壳辅助模块，主要用于从运行中的目标应用提取 DEX 文件，帮助研究人员进一步进行代码审计、兼容性分析和应用行为研究。

模块支持多种脱壳方式，可根据目标应用和设备环境选择合适的模式。对于需要在运行时才恢复代码的应用，还提供类加载、深度脱壳和受控主动调用等辅助功能。

## 主要用途

- 提取目标应用运行时加载的 DEX 文件
- 处理部分动态加载、内存加载和运行时恢复代码的应用
- 记录方法及 code-item 信息，辅助后续分析
- 按类名规则选择或排除需要主动调用的类
- 为反编译、代码审计和安全研究提供较完整的分析文件

## 使用说明

在模块设置中选择授权方式、脱壳模式及所需的辅助功能，然后为目标应用写入配置。启用模块并重新启动目标应用后，可通过目标应用内的悬浮菜单执行脱壳和相关操作。

主动调用和深度脱壳可能执行目标应用中的代码，建议仅在测试设备或可控环境中使用，并提前备份重要数据。

本项目仅用于合法的软件分析、安全研究和学习交流。请勿用于未获授权的应用或其他违法用途。
